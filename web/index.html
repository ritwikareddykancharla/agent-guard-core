Abstract

AgentGuard sits at the VPC egress boundary between autonomous multi-agent workflows and external or cloud foundation models. Before any prompt or retrieved RAG document reaches an LLM, AgentGuard deterministically replaces SSNs, AWS access keys, payment cards, MRNs, emails, and phones with HMAC-keyed placeholders ([PII_SSN_1]), screens untrusted context for indirect prompt injections, enforces attenuated HMAC-SHA256 capability tokens across Agent-to-Agent (A2A) handoffs, and audits microservice manifests to synthesize ready-to-apply security patches with Amazon Bedrock (us.amazon.nova-lite-v1:0).

02Problem & AWS team alignment

Enterprise AI assistants routinely ingest support tickets containing SSNs, payment cards, and leaked cloud credentials, retrieve untrusted third-party documents, and delegate subtasks across worker agents. Passing raw text or parent IAM credentials across these boundaries creates three structural vulnerabilities: outbound PII disclosure, indirect prompt-injection hijacking, and confused-deputy privilege escalation.

  • Security Automation & Service Posture Remediation: Deterministic manifest auditing paired with us.amazon.nova-lite-v1:0 pinpoints wildcard IAM actions (*), unpinned tool allowlists, and missing VPC PII filters, then emits a verifiable unified diff that lifts service posture to 100/100.
  • Autonomous AI Security & Scoped A2A Delegation: Every sub-agent handoff mints an attenuated HMAC-SHA256 token binding human_principal_id, chain_of_custody, glob-subsumed tool names, AWS resource ARNs, and USD spend caps.
  • Sensitive Content Intelligence & Responsible AI Policies: Deterministic tokenization preserves entity co-reference across multi-turn reasoning while selectively re-hydrating only permitted categories per downstream tool ACL.
