How It Works (30-Second Visual Walkthrough)

Four composable defense-in-depth subsystems engineered for AWS Applied AI Core Services, Luna GenAI Gateway, and Amazon Connect multi-agent architectures.

Pillar 01 · identity_delegation.py

Zero-Trust A2A Delegation & JIT Proxy

Every agent action requires an HMAC-SHA256 capability token binding human_principal_id, agent_id, parent_agent_id, allowed tool globs, AWS ARN patterns, and USD budget. Sub-agents can only narrow permissions. High-risk calls (WIRE_TRANSFER, PROD_DEPLOY, IAM_MUTATE, DELETE) suspend into PENDING_JIT_APPROVAL until signed by a human approver.

Pillar 02 · pii_firewall.py

Reversible Pre-Context PII & Injection Firewall

Before prompts or RAG docs touch the LLM context window, 6 sensitive entity classes (SSN, AWS_ACCESS_KEY, CREDIT_CARD, EMAIL, PHONE, PATIENT_MRN) are tokenized into deterministic placeholders (<PII:SSN_001>, <PII:AWS_KEY_001>) and selectively re-hydrated only for permitted tools while blocking indirect prompt injections.

Pillar 03 · memory_mcp.py

3-Tier Hierarchical Memory MCP Server

Solves context window amnesia across long sessions: Tier 1 Working Memory pins system guardrails inside a tight token budget; evicted turns compact into Tier 2 Episodic Summaries with exponential temporal decay; salient enterprise facts promote into Tier 3 Semantic Memory (TF-IDF + entity boost) with turn provenance.

Pillar 04 · model_gateway.py

Multi-Model Semantic Cache & Kill-Switch

Routes ~90% of routine operational traffic to low-latency fast models (nova-micro / gpt-4o-mini) and escalates complex multi-tool verification to reasoning models (claude-opus-5-5), backed by a tenant-isolated Semantic Cache, token-bucket rate limiter, runaway loop breaker, and USD cost kill-switch.
